بعضی تنظیمات باید روی همهٔ سرورها یکسان باشند، وگرنه سرورها نمی‌توانند با هم ارتباط بگیرند.
**SafeSync** این تنظیمات را در یک قدم و از پنل هر سروری، همه‌جا تغییر می‌دهد، و مطمئن می‌شود یک
تغییر اشتباه هیچ سروری را از مش جدا نکند.

## چه چیزهایی را تغییر می‌دهد

| مشترک بین همهٔ سرورها | مخصوص هر سرور |
| :--- | :--- |
| پروتکل انتقال | نام سرور |
| رمز شبکه | آی‌پی مجازی |
| رمزنگاری | پورت شنود |
| مقاومت در برابر اتلاف بسته (KCP) | حالت چندنخی (Multi-thread) |
| IPv6 | تونل‌ها |
| MTU | |

## اعمال تغییر روی همهٔ سرورها

<Steps>

1. <UiPath items={['نود', 'تنظیمات']} /> را باز کنید و یک یا چند تنظیم مشترک را تغییر دهید.

2. در نوار **تغییرات ذخیره‌نشده**، **اعمال روی همهٔ سرورها** را بزنید. این دکمه فقط وقتی دیده
   می‌شود که همهٔ تغییرهایتان از تنظیمات مشترک باشند. اگر چیزی مخصوص همین سرور را هم عوض
   کرده‌اید، با **ذخیره روی این سرور** ذخیره کنید.

3. خلاصه را بررسی کنید: تنظیماتی که عوض می‌شوند و سرورهایی که آن‌ها را دریافت می‌کنند. برای تأیید،
   **اعمال روی همهٔ سرورها** را بزنید.

4. وقتی همهٔ سرورها تغییر را اعمال کردند و دوباره وصل شدند، پیام **مش هماهنگ شد** را می‌بینید.

</Steps>

## چطور ایمن می‌ماند

- **امضاشده.** هر سرور پیش از اعمال تغییر بررسی می‌کند که با رمز شبکه امضا شده باشد
  (HMAC-SHA256). سرورهای بیرون از مش نمی‌توانند تنظیماتی به مش شما بفرستند.
- **با پشتیبان.** هر سرور پیش از اعمال تنظیمات تازه، تنظیمات فعلی‌اش را ذخیره می‌کند.
- **پشتیبان ایمنی ۹۰ ثانیه‌ای.** اگر سروری تا ۹۰ ثانیه بعد از تغییر هیچ همتای وصل‌شده‌ای نداشته
  باشد، تنظیمات قبلی‌اش را برمی‌گرداند و خودش دوباره وصل می‌شود.

:::note
فقط سرورهایی تغییر را دریافت می‌کنند که در همان لحظه وصل باشند. پیش از هر چیز بررسی کنید همهٔ
سرورهایتان در بخش **سرورها** دیده شوند. سروری که آفلاین بوده تنظیمات قدیمی‌اش را نگه می‌دارد؛ آن
را از پنل خودش به‌روز کنید.
:::
