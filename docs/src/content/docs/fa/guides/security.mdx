XRayMesh از همان ابتدا خصوصی است. این صفحه توضیح می‌دهد چه چیزهایی از پنل و مش محافظت می‌کنند و
تصمیم دربارهٔ چه چیزهایی با خود شماست.

## ورود

هنگام نصب یکی از دو حالت را انتخاب می‌کنید. هر وقت خواستید، با `sudo xraymesh password` آن را
عوض کنید.

| حالت | روش ورود | چرا این حالت |
| :--- | :--- | :--- |
| **فقط لینک ورود** (پیش‌فرض) | با `sudo xraymesh token` لینکی بگیرید که فقط یک بار و تا ۶۰ دقیقه کار می‌کند. | رمزی وجود ندارد، پس چیزی برای حدس زدن یا حملهٔ brute-force نیست. |
| **رمز و لینک ورود** | با رمز مدیر یا با لینک ورود وارد شوید. | اگر پنل را زیاد و از دستگاه‌های مختلف باز می‌کنید، راحت‌تر است. |

در هر دو حالت، پنل:

- توکن ورود را بلافاصله بعد از ورود از نوار نشانی پاک می‌کند تا در تاریخچهٔ مرورگر نماند،
- بعد از ۵ تلاش ناموفق، ورود از آن آی‌پی را تا پایان همان دقیقه مسدود می‌کند،
- شما را تا ۷ روز در همان مرورگر وارد نگه می‌دارد.

## HTTPS

بدون HTTPS، پنل روی HTTP ساده اجرا می‌شود و کوکی نشست شما در شبکه قابل خواندن است. اگر دامنه
دارید، HTTPS را روشن کنید:

```bash
sudo xraymesh ssl
```

اول دامنه را به سرور وصل کنید. XRayMesh رکورد DNS را بررسی می‌کند، یک گواهی رایگان از Let's Encrypt
می‌گیرد و خودکار تمدیدش می‌کند. هنگام گرفتن گواهی، پورت `80` باید در دسترس باشد. اگر سرویس دیگری
از پورت ۸۰ استفاده کند، XRayMesh پیشنهاد می‌دهد آن را چند ثانیه متوقف کند. با HTTPS روشن، کوکی نشست
فقط از راه HTTPS فرستاده می‌شود.

برای برگشتن به HTTP، `sudo xraymesh remove-ssl` را اجرا کنید.

## مش

- **مش خصوصی.** هر سرور فقط سرورهایی را می‌پذیرد که رمز شبکهٔ یکسانی دارند، پس هیچ کس دیگری
  نمی‌تواند از آن به‌عنوان relay رایگان EasyTier استفاده کند.
- **رمزنگاری.** ترافیک مش به‌طور پیش‌فرض با AES-GCM رمزنگاری می‌شود. آن را فقط برای مشی دوسروری
  روی ICMP یا PCK خاموش کنید، که BackPack خودش رمزنگاری‌اش می‌کند.
- **تغییرهای امضاشده.** تنظیماتی که با [SafeSync](../safesync/) فرستاده می‌شوند و به‌روزرسانی‌هایی
  که از پنل سرور دیگر شروع می‌شوند، با رمز شبکه امضا می‌شوند. سرورها هر چیز دیگری را رد می‌کنند.

:::caution[کد دعوت را مثل رمز عبور نگه دارید]
رمز شبکه داخل کد دعوت است. هر کسی که آن را داشته باشد می‌تواند به مش شما بپیوندد. آن را فقط از
راه یک کانال خصوصی بفرستید. اگر لو رفت، **رمز شبکه** را عوض کنید و **اعمال روی همهٔ سرورها** را
بزنید.
:::

## فایروال

اگر UFW فعال باشد، نصب‌کننده پورت پنل وب و پورت مش را باز می‌کند. برای تونل‌ها فقط پورت‌هایی را باز
کنید که کاربرانتان لازم دارند. برای اینکه پنل سخت‌تر پیدا شود، با `sudo xraymesh port` آن را از
پورت پیش‌فرض جابه‌جا کنید.
