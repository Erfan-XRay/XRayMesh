هر سرور خودش نسخه‌های تازه را از GitHub بررسی می‌کند. هر سرور مش را می‌توانید از پنل هر سروری
به‌روز کنید، و اگر به‌روزرسانی شکست بخورد، نسخهٔ قبلی خودکار برمی‌گردد.

## به‌روزرسانی از پنل

<Steps>

1. بخش **سرورها** را باز کنید. سروری که نسخهٔ تازه برایش آمده، برچسب **به‌روزرسانی موجود** دارد.

2. روی آن سرور **به‌روزرسانی به** *نسخه* را بزنید. پنجرهٔ باز شده نسخه و کانال فعلی را نشان
   می‌دهد.

3. **به‌روزرسانی کن** را بزنید. سرور:
   - فایل‌های تازه را دانلود و پیش از جایگزینی هر چیزی بررسی می‌کند،
   - سرویس‌هایش را حدود ۲۰ ثانیه ری‌استارت می‌کند، پس ترافیک مشی که از آن می‌گذرد کوتاه قطع می‌شود،
   - اگر سالم برنگردد، خودش نسخهٔ قبلی را برمی‌گرداند.

4. پیشرفت کار در ردیف همان سرور نمایش داده می‌شود: دانلود، بررسی فایل‌ها، نصب و ری‌استارت. اگر
   سروری را به‌روز کنید که پنلش را باز کرده‌اید، پنل در پایان خودش دوباره بارگذاری می‌شود و ممکن
   است لازم باشد دوباره وارد شوید.

</Steps>

:::note[اگر به‌روزرسانی تمام نشد]
اگر بعد از ۴ دقیقه تأییدی نیامد، پنل خود آن سرور را باز کنید یا لاگ به‌روزرسان را روی سرور
ببینید:

```bash
journalctl -u xraymesh-updater-temp
```
:::

## پایدار یا بتا

هر سرور **کانال به‌روزرسانی** خودش را دارد که کنار نسخه‌اش نمایش داده می‌شود. برای تغییر، روی آن
بزنید.

| کانال | چه دریافت می‌کنید |
| :--- | :--- |
| **پایدار** | نسخه‌های آزموده‌شده. پیش‌فرض است و برای سرورهایی که به آن‌ها متکی هستید انتخاب درستی است. |
| **بتا** | قابلیت‌های تازه زودتر می‌رسند، اما ممکن است ناپایدار یا ناقص باشند. برای آزمایش از آن استفاده کنید. |

تغییر کانال به‌تنهایی چیزی نصب نمی‌کند و همچنان باید **به‌روزرسانی** را بزنید. برگشتن از بتا به
پایدار هرگز نسخه را پایین نمی‌آورد: سرور روی نسخهٔ فعلی‌اش می‌ماند تا یک نسخهٔ پایدار جدیدتر
منتشر شود.

## به‌روزرسانی از ترمینال

این روش برای سروری است که در پنل آفلاین است، یا نسخهٔ قدیمی‌ای دارد که از راه دور به‌روز نمی‌شود
(پنل برچسب **نیازمند به‌روزرسانی** را نشان می‌دهد).

<Tabs>
<TabItem label="xraymesh نصب است">

```bash
sudo xraymesh update
```

</TabItem>
<TabItem label="دستور xraymesh پیدا نمی‌شود">

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Erfan-XRay/XRayMesh/main/xraymesh.sh) update
```

</TabItem>
</Tabs>

این کار اسکریپت، پنل وب و هستهٔ EasyTier را به‌روز می‌کند.
