---
title: دستورهای ترمینال
description: همهٔ دستورهای xraymesh، دسته‌بندی‌شده بر اساس کاربرد.
---

اگر `xraymesh` را بدون هیچ آرگومانی اجرا کنید، منوی تعاملی ترمینال باز می‌شود. همهٔ دستورهای زیر
به‌تنهایی هم کار می‌کنند و برای اسکریپت‌نویسی مناسب‌اند. بیشترشان سیستم را تغییر می‌دهند، پس آن‌ها
را با `root` یا `sudo` اجرا کنید.

:::tip
مدیریت روزمرهٔ مش در پنل وب انجام می‌شود. ترمینال برای راه‌اندازی است، و برای برگشتن به پنل
وقتی مشکلی پیش آمده.
:::

## دسترسی به پنل

| دستور | کاری که انجام می‌دهد |
| :--- | :--- |
| `xraymesh token` | یک لینک ورود یک‌بارمصرف تازه می‌سازد که ۶۰ دقیقه اعتبار دارد. |
| `xraymesh password` | رمز مدیر را تعیین، عوض یا حذف می‌کند. |
| `xraymesh port` | پورت پنل وب را عوض می‌کند. |
| `xraymesh ssl` | یک گواهی رایگان از Let's Encrypt می‌گیرد و پنل را به HTTPS می‌برد. |
| `xraymesh remove-ssl` | پنل را به HTTP ساده برمی‌گرداند. |

## مش

| دستور | کاری که انجام می‌دهد |
| :--- | :--- |
| `xraymesh join` | با کد دعوت (`xrmesh://…`) به یک مش می‌پیوندد. |
| `xraymesh invite` | کد دعوت این سرور را نشان می‌دهد. |
| `xraymesh status` | وضعیت نود، مش و پنل را نشان می‌دهد. |
| `xraymesh peers` | همتاهای وصل‌شده را با تأخیر زنده نشان می‌دهد. |
| `xraymesh routes` | جدول مسیریابی مش را نشان می‌دهد. |
| `xraymesh link-list` | لینک‌های ICMP و PCK را با شمارندهٔ بسته‌هایشان نشان می‌دهد. |
| `xraymesh link-delete <name>` | یک لینک ICMP یا PCK را حذف می‌کند، مثلاً `out-1234`. |

## سرویس‌ها

| دستور | کاری که انجام می‌دهد |
| :--- | :--- |
| `xraymesh start` | تنظیمات نود را اعمال می‌کند و همهٔ سرویس‌ها را راه می‌اندازد. |
| `xraymesh restart` | همهٔ سرویس‌های XRayMesh را ری‌استارت می‌کند. |
| `xraymesh stop` | همهٔ سرویس‌های XRayMesh را متوقف می‌کند. |
| `xraymesh logs` | لاگ‌های مش و پنل را زنده نشان می‌دهد. برای خروج <kbd>Ctrl</kbd>+<kbd>C</kbd> را بزنید. |
| `xraymesh self-test` | نصب، سرویس‌ها و اتصال را بررسی می‌کند و مشکل‌ها را گزارش می‌دهد. |

## نگهداری

| دستور | کاری که انجام می‌دهد |
| :--- | :--- |
| `xraymesh update` | اسکریپت، پنل وب و هستهٔ EasyTier را به‌روز می‌کند. |
| `xraymesh delete` | تنظیمات مش این نود را حذف می‌کند. برنامه‌های نصب‌شده می‌مانند. |
| `xraymesh uninstall` | XRayMesh را کامل حذف می‌کند: سرویس‌ها، تنظیمات و برنامه‌ها. |
| `xraymesh version` | نسخهٔ نصب‌شده را نشان می‌دهد. |
| `xraymesh help` | فهرست دستورها را نشان می‌دهد. |

:::danger[delete و uninstall برگشت‌پذیر نیستند]
`delete` این سرور را از مش خارج می‌کند. `uninstall` پنل، تونل‌ها و همهٔ تنظیمات را هم پاک
می‌کند. برای تأیید باید `DELETE` یا `REMOVE` را تایپ کنید.
:::
