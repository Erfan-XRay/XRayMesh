## سرورها

| پیش‌نیاز | پشتیبانی‌شده |
| :--- | :--- |
| سیستم‌عامل | Debian 11 یا 12، و Ubuntu 20.04، 22.04 یا 24.04 |
| معماری پردازنده | `x86_64`، `aarch64` (ARM64) یا `armv7` |
| دسترسی | کاربر `root` یا کاربری با `sudo` |
| سیستم init | systemd |

برای ساختن مش دست‌کم به دو سرور نیاز دارید. نصب‌کننده وجود `curl`، `python3`، `iproute2`،
`jq`، `openssl`، `iperf3` و چند بستهٔ دیگر را بررسی می‌کند و هر کدام را که نباشد با `apt` نصب
می‌کند.

## پورت‌ها

این پورت‌ها را در فایروال سرویس‌دهندهٔ سرورتان باز کنید. اگر UFW روی سرور فعال باشد، نصب‌کننده
پورت‌های پنل وب و مش را خودش باز می‌کند.

| پورت | پروتکل | کاربرد |
| :--- | :--- | :--- |
| `11080` | TCP | پنل وب. می‌توانید هنگام نصب یا بعداً با `xraymesh port` آن را عوض کنید. |
| `11010` | TCP و UDP | ترافیک مش بین سرورها. پورت شنود را می‌توانید هنگام ساخت مش عوض کنید. |
| `80` | TCP | فقط هنگام گرفتن گواهی رایگان HTTPS از Let's Encrypt. |

:::note[پروتکل‌های ICMP و PCK]
برای ICMP باید ترافیک پینگ (ICMP) بین سرورها مجاز باشد. هر لینک PCK روی سروری که کد دعوت را
می‌سازد، یک پورت TCP جداگانه بین `20000` و `32767` باز می‌کند. پنل این پورت را کنار کد نشان
می‌دهد؛ آن را در فایروال سرویس‌دهنده باز کنید.
:::

## اختیاری: دامنه

اگر می‌خواهید پنل را با HTTPS باز کنید، پیش از نصب یک دامنه (مثلاً `panel.example.com`) را به
سرور وصل کنید. XRayMesh برای آن یک گواهی رایگان از Let's Encrypt می‌گیرد و خودکار تمدیدش می‌کند.
بدون دامنه، پنل با HTTP ساده روی آی‌پی سرور اجرا می‌شود.
