این کار را **فقط یک بار** و روی اولین سرور انجام دهید. همهٔ سرورهای دیگر به مشی می‌پیوندند که
این سرور می‌سازد.

<Steps>

1. در صفحهٔ **راه‌اندازی این سرور**، گزینهٔ **ساخت مش تازه** را انتخاب کنید.

2. **اطلاعات اصلی را وارد کنید.** مقدارهای پیش‌فرض درست کار می‌کنند و معمولاً می‌توانید همان‌ها
   را نگه دارید.

   | فیلد | پیش‌فرض | معنی |
   | :--- | :--- | :--- |
   | نام سرور | نام میزبان (hostname) همین سرور | در فهرست همتاها، پینگ و تست سرعت به سرورهای دیگر نشان داده می‌شود. |
   | نام شبکه | `xraymesh` | روی همهٔ سرورها باید یکسان باشد. کد دعوت آن را با خودش می‌برد. |
   | آی‌پی مجازی | `10.144.144.1` | نشانی خصوصی این سرور در مش. باید یکتا باشد. |

3. **تنظیمات پیشرفته را بررسی کنید (اختیاری).** برای تغییر پروتکل یا هر چیز دیگر،
   **تنظیمات پیشرفته** را باز کنید. مقدارهای پیش‌فرض برای شروع مناسب‌اند:

   | گزینه | پیش‌فرض |
   | :--- | :--- |
   | رمز شبکه | خودکار ساخته می‌شود. آن را خصوصی نگه دارید. |
   | پورت شنود | `11010` |
   | پروتکل | `dual` (TCP و UDP؛ مسیر سریع‌تر خودکار انتخاب می‌شود) |
   | رمزنگاری | روشن (AES-GCM). روی همهٔ سرورها باید یکسان باشد. |
   | حالت چندنخی (Multi-thread) | روشن. از بیش از یک هستهٔ CPU استفاده می‌کند. |
   | MTU | `1360` (برای ICMP ‏`1280`) |

4. **دکمهٔ ساخت مش را بزنید.** سرویس مش راه می‌افتد و پیام **مش xraymesh آماده است** همراه با کد
   دعوت نمایش داده می‌شود.

5. **کد دعوت را کپی کنید.** این کد با `xrmesh://` شروع می‌شود و روی همهٔ سرورهای دیگر به آن
   نیاز دارید.

</Steps>

:::caution[کد دعوت را خصوصی نگه دارید]
رمز شبکه داخل این کد است. هر کسی که آن را داشته باشد می‌تواند به مش شما بپیوندد.
:::

## پیدا کردن دوبارهٔ کد دعوت

هر وقت خواستید، کد را از <UiPath items={['نود', 'همتاها و دعوت']} /> بردارید. کارت
**دعوت از سرور دیگر** کد را همراه با نشانی‌ای که سرورهای دیگر برای وصل شدن به این سرور به کار
می‌برند نشان می‌دهد.

اگر پنل گفت آی‌پی عمومی شناسایی نشد، کنار آن نشانی **تغییر** را بزنید و پیش از کپی کردن کد،
آی‌پی عمومی یا دامنهٔ این سرور را وارد کنید. در غیر این صورت سرورهای دیگر نمی‌دانند به کجا وصل
شوند.
