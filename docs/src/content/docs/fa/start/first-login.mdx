## باز کردن پنل

لینک ورود یک‌بارمصرفی را که نصب‌کننده نشان داد باز کنید. پنل شما را وارد می‌کند و توکن را از
نوار نشانی پاک می‌کند تا در تاریخچهٔ مرورگر باقی نماند.

پنل روی نشانی سرور و پورتی که انتخاب کرده‌اید در دسترس است، مثلاً
`http://203.0.113.10:11080`، یا با HTTPS نشانی `https://panel.example.com:11080`.
در همان مرورگر تا **۷ روز** وارد می‌مانید.

## گرفتن لینک ورود تازه

لینک‌های ورود پس از ۶۰ دقیقه منقضی می‌شوند و فقط یک بار کار می‌کنند. برای گرفتن لینک تازه، این
دستور را روی سرور اجرا کنید:

```bash
sudo xraymesh token
```

اگر هنگام نصب رمز تعیین کرده باشید، در صفحهٔ ورود با آن هم می‌توانید وارد شوید. برای تعیین،
تغییر یا حذف رمز، `sudo xraymesh password` را اجرا کنید.

:::caution[رمز اشتباه پشت سر هم]
پس از ۵ تلاش ناموفق در یک دقیقه، پنل ورود از آن آی‌پی را تا پایان همان دقیقه مسدود می‌کند. اگر
رمز را فراموش کرده‌اید، به‌جای حدس زدن یک لینک ورود تازه بگیرید.
:::

## صفحهٔ اول: راه‌اندازی این سرور

سرور تازه با صفحهٔ **راه‌اندازی این سرور** باز می‌شود. تا این مرحله تمام نشود، بخش‌های دیگر
(سرورها، تونل‌ها، پینگ و تست سرعت) قفل می‌مانند. دو انتخاب دارید:

| انتخاب | چه وقت |
| :--- | :--- |
| **ساخت مش تازه** | این اولین سرور شماست. خودش مش می‌شود و برای سرورهای دیگر کد دعوت می‌گیرید. |
| **پیوستن به مش موجود** | از قبل مش دارید و کد دعوتش را در اختیار دارید. |

:::tip[پنل را مثل اپ نصب کنید]
روی گوشی، پنل را به صفحهٔ اصلی اضافه کنید (در Safari: ‏Share و بعد Add to Home Screen؛ در
Chrome: ‏Install app). پنل تمام‌صفحه و با آیکون خودش باز می‌شود.
:::
