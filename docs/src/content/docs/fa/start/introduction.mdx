XRayMesh چند سرور لینوکسی را به یک شبکهٔ خصوصی تبدیل می‌کند. هر سرورِ عضو مش یک نشانی خصوصی
می‌گیرد و از راه یک لینک رمزنگاری‌شده مستقیم به سرورهای دیگر دسترسی دارد، فرقی نمی‌کند کجا
میزبانی شده باشند. روی همین مش می‌توانید بین سرورها پورت فوروارد کنید، سرعت و تأخیر را بسنجید و
تنظیمات را هم‌زمان روی همهٔ سرورها تغییر دهید. همهٔ این کارها از پنل وب انجام می‌شود.

## اصطلاح‌هایی که می‌بینید

<dl class="xr-terms">
	<div>
		<dt>نود</dt>
		<dd>هر سروری که XRayMesh رویش اجرا می‌شود. هر نود پنل وب خودش را دارد.</dd>
	</div>
	<div>
		<dt>مش</dt>
		<dd>همهٔ نودهایی که نام شبکه و رمز شبکهٔ یکسانی دارند. این نودها همدیگر را پیدا می‌کنند و ترافیک را بین خودشان جابه‌جا می‌کنند.</dd>
	</div>
	<div>
		<dt>آی‌پی مجازی</dt>
		<dd>نشانی خصوصی نود درون مش، مثل <code>10.144.144.1</code>. این نشانی باید در مش یکتا باشد.</dd>
	</div>
	<div>
		<dt>کد دعوت</dt>
		<dd>کدی که با <code>xrmesh://</code> شروع می‌شود و هر چیزی را که سرور تازه برای پیوستن لازم دارد در خودش دارد؛ فقط کافی است آن را وارد کنید.</dd>
	</div>
	<div>
		<dt>پروتکل انتقال</dt>
		<dd>روشی که ترافیک مش بین سرورها جابه‌جا می‌شود: TCP، UDP، WebSocket، QUIC، FakeTCP، ICMP یا PCK. همهٔ نودهای یک مش از یک پروتکل استفاده می‌کنند.</dd>
	</div>
</dl>

## روی هر سرور چه اجرا می‌شود

| بخش | کاری که انجام می‌دهد |
| :--- | :--- |
| هستهٔ EasyTier | مش رمزنگاری‌شده را می‌سازد و ترافیک را بین نودها مسیریابی می‌کند. |
| پنل وب | جایی که نود را راه‌اندازی می‌کنید، سرور اضافه می‌کنید، تونل می‌سازید و ترافیک زنده را می‌بینید. به‌طور پیش‌فرض روی پورت `11080` است. |
| تونل‌ها | HAProxy، Realm، GOST یا iptables که از پنل تنظیم می‌شوند تا پورت‌ها را روی مش فوروارد کنند. |
| دستور `xraymesh` | منوی ترمینال برای راه‌اندازی اولیه و بازیابی، مثل گرفتن لینک ورود تازه یا ری‌استارت سرویس‌ها. |

راه اصلی مدیریت XRayMesh پنل وب است. ترمینال را فقط برای نصب لازم دارید، و برای وقتی که
نمی‌توانید وارد پنل شوید.
