## What you get

<CardGrid>
	<Card title="Private mesh" icon="random">
		Every server gets a private address like `10.144.144.2` and reaches the others directly,
		encrypted, through [EasyTier](https://github.com/EasyTier/EasyTier).
	</Card>
	<Card title="Nine transports" icon="rocket">
		TCP, UDP, WebSocket, QUIC, FakeTCP, and ICMP or PCK links for networks where almost
		nothing else gets through.
	</Card>
	<Card title="Web panel" icon="laptop">
		Live peers, latency and traffic, speed tests and ping between servers. English and Persian,
		light and dark, installable on your phone.
	</Card>
	<Card title="Port forwarding" icon="setting">
		Forward ports across the mesh with HAProxy, Realm, GOST or kernel iptables, from single
		ports to whole ranges.
	</Card>
	<Card title="SafeSync" icon="approve-check-circle">
		Push a config change to every server at once. If a server loses its peers, it rolls back
		on its own.
	</Card>
	<Card title="Secure by default" icon="padlock">
		One-time login links, optional password-free mode, login rate limiting and free HTTPS
		with Let's Encrypt.
	</Card>
</CardGrid>

## Built on

The mesh runs on [EasyTier](https://github.com/EasyTier/EasyTier). The ICMP and PCK transports come
from [BackPack](https://github.com/AminMGMT/BackPack). Both are downloaded as
official, checksum-verified releases and run unmodified.
