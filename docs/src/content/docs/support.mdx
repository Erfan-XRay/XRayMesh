XRayMesh is free for personal use and built by one developer. If it keeps your servers connected,
a donation helps pay for test servers and the time that goes into every release. Thank you.

:::caution[Check the network before you send]
Send each coin **only on the network shown next to it**. For example, USDT must go over **TRC20
(Tron)**. Coins sent on another network, such as USDT on ERC20 or BEP20, are lost and can't be
recovered.
:::

<Wallets />

## Other ways to help

- **Star the project** on [GitHub](https://github.com/Erfan-XRay/XRayMesh). It helps other people
  find it.
- **Report problems** with the details from [Troubleshooting](../troubleshooting/#still-stuck), so
  they get fixed faster.
- **Tell others** who run servers in more than one place.
- **Thank the projects it builds on:** [EasyTier](https://github.com/EasyTier/EasyTier) and
  [BackPack](https://github.com/AminMGMT/BackPack) welcome stars too.
