Each server checks GitHub for new releases on its own. You can update any server in the mesh from
any panel, and a failed update restores the previous version automatically.

## Update from the panel

<Steps>

1. Open the **Servers** tab. A server with a new release shows **Update available**.

2. Press **Update to** *version* on that server. The dialog shows the version it runs now.

3. Press **Update now**. The server:
   - downloads the new files and verifies them before replacing anything,
   - restarts its services for about 20 seconds, so mesh traffic through it pauses briefly,
   - restores the previous version on its own if it doesn't come back healthy.

4. The progress appears in the server's row: downloading, verifying, installing, restarting. When you
   update the server whose panel you're in, the panel reloads by itself when it's done. You may need
   to sign in again.

</Steps>

:::note[If an update doesn't finish]
If there's no confirmation after 4 minutes, open that server's own panel, or check the updater log
on the server:

```bash
journalctl -u xraymesh-updater-temp
```
:::

:::note[Beta channel removed]
Since 3.0.2 every server updates from the regular releases only. A server that was set to the beta
channel in an older version is moved to the regular releases the next time you update it.
:::

## Update from the terminal

Use this for a server that's offline in the panel, or one running an old version that can't be
updated remotely (the panel shows **Needs update**).

<Tabs>
<TabItem label="xraymesh installed">

```bash
sudo xraymesh update
```

</TabItem>
<TabItem label="xraymesh command missing">

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Erfan-XRay/XRayMesh/main/xraymesh.sh) update
```

</TabItem>
</Tabs>

This updates the script, the web panel and the EasyTier core.
