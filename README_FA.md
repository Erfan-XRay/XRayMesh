## معرفی پروژه

**XRayMesh** یک ابزار پیشرفته، سبک و کامل برای راه‌اندازی و مدیریت شبکه‌های مش رمزنگاری‌شده بین سرورهای لینوکس است. با استفاده از هسته قدرتمند **EasyTier**، سرورهای شما در لوکیشن‌های مختلف (ایران و خارج) با یک شبکه خصوصی امن و پایدار به یکدیگر متصل می‌شوند. نسخه ۲.۱.۰ با یک **داشبورد تحت وب مدرن (Web UI)**، قابلیت‌های پایش آنی، فورواردینگ ترافیک با ۴ ابزار قدرتمند، تست سرعت داخلی و امنیت ارتقایافته عرضه شده است.

توسعه‌داده‌شده توسط **ErfanXRay**.

## قابلیت‌های کلیدی

### 🌐 شبکه مش بدون پیچیدگی (Zero-Config Mesh)
- اتصال چندین سرور به یک شبکه خصوصی امن با رنج آی‌پی اختصاصی (`10.144.144.0/24`).
- **پروتکل‌های ارتباطی متنوع:** حالت دوگانه TCP/UDP، حالت WSS (WebSocket بر بستر TLS) و پروتکل مدرن QUIC.
- **بهینه‌ساز KCP:** قابلیت فعال‌سازی شتاب‌دهنده KCP برای لینک‌های با پکت‌لاس بالا.
- **پایداری سرویس:** راه‌اندازی به عنوان سرویس سیستمی systemd با ریکاوری و ریستارت خودکار در صورت قطعی.

### 💻 داشبورد تحت وب پیشرفته (Web UI)
- **مانیتورینگ زنده:** مشاهده وضعیت نودها، پینگ لحظه‌ای، حجم دیتای تبادل‌شده (RX/TX)، مسیرهای بهینه و لود سرور (CPU / RAM).
- **برجسته‌سازی نود جاری:** نود فعلی همیشه با نشانگر رنگی مجزا و بالاتر از سایر پیرها نمایش داده می‌شود.
- **کانفیگ دسته‌بندی‌شده و خلوت:** بخش پیکربندی نود به ۴ تب سبک (شناسه نود، پروتکل و پورت، کد دعوت کلاستر، و عملیات حساس) تفکیک شده تا از شلوغی جلوگیری شود.
- **تست سرعت داخل شبکه مش (In-Mesh Speedtest):** بنچمارک پهنای‌باند با **iperf3** در حالت TCP و بررسی Jitter و درصد Packet Loss در حالت UDP.
- **تست پینگ تعاملی:** اندازه‌گیری دقیق تاخیر و پکت‌لاس بین سرورها با یک کلیک.
- **طراحی زیبا و ریسپانسیو:** ۵ پالت رنگی سایبرپانک، منوی موبایل کاربرپسند و پشتیبانی کامل از زبان‌های فارسی (راست‌چین) و انگلیسی.

### 🛡️ مدیریت ۴ گانه تونل‌های فورواردینگ
- **تونل‌های HAProxy:** پروکسی پرسرعت TCP با لود بالانسینگ و بررسی سلامت سرور.
- **تونل‌های Realm:** فورواردر فوق‌العاده سبک و بهینه نوشته‌شده با زبان Rust برای هر دو پروتکل TCP و UDP.
- **تونل‌های GOST v3:** موتور چندمنظوره فورواردینگ در فضای کاربری.
- **تونل‌های هسته لینوکس (iptables):** فوروارد نیتیو در سطح کرنل (DNAT + MASQUERADE) با کمترین تاخیر برای پروتکل‌های UDP سنگین (مانند Hysteria2 و WireGuard).
- پشتیبانی از پورت‌های تکی (`443`)، لیستی (`80,443`) و بازه‌ای (`8000-8020`).

### ⚡ همگام‌سازی هوشمند کلاستر (SafeSync)
- امکان اعمال کانفیگ‌های جدید شبکه مش روی تمام سرورهای کلاستر به صورت همزمان.
- **سگ نگهبان ایمنی (Watchdog ۹۰ ثانیه‌ای):** در صورتی که تغییر کانفیگ باعث قطع اتصال سرور با شبکه شود، سیستم به طور خودکار به آخرین نسخه پشتیبان سالم برمی‌گردد تا دسترسی به سرور از دست نرود.

### 🔐 امنیت و اعتبارسنجی پیشرفته
- **ورود سریع تک‌کلیکه:** تولید توکن موقت با دستور `sudo xraymesh token` برای ورود آنی بدون نیاز به رمز.
- **پاکسازی خودکار آدرس مرورگر:** توکن لاگین به محض ورود از تاریخچه و نوار آدرس پاک می‌شود.
- **سیستم ضد بروت‌فورس (Rate Limiter):** مسدودسازی خودکار تلاش‌های ناموفق لاگین برای جلوگیری از حملات دیکشنری.
- **کوکی امن HTTPS:** افزودن خودکار صفت `Secure` به کوکی سشن در صورت وجود گواهی SSL.
- **تنظیم خودکار فایروال UFW:** باز کردن هوشمند پورت وب و مش در صورت روشن بودن فایروال سرور.

## نحوه نصب و راه‌اندازی

دستور زیر را در ترمینال سرور اوبونتو یا دبیان خود اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Erfan-XRay/XRayMesh/main/xraymesh.sh)
```

در فرایند نصب:
1. هسته EasyTier به صورت کاملاً خودکار و با اعتبارسنجی هش SHA-256 نصب می‌شود.
2. در صورت داشتن دامنه، می‌توانید گواهی رایگان SSL (HTTPS) را فعال کنید.
3. می‌توانید رمز عبور تعیین کنید یا حالت **فقط توکن (Token-Only)** را برای بالاترین سطح امنیت انتخاب نمایید.
4. در پایان، لینک ورود مستقیم به داشبورد وب در ترمینال نمایش داده می‌شود.

برای دسترسی به منوی متنی ترمینال در هر زمان، کافیست دستور زیر را وارد کنید:
```bash
xraymesh
```

## راهنمای اتصال دو سرور به یکدیگر

### سرور اول (سرور مادر)
1. وارد وب پنل یا منوی ترمینال شوید و مشخصات شبکه را تعیین کنید:
   - **نام شبکه:** به عنوان مثال `xraymesh`
   - **رمز شبکه:** رمز امنیتی تصادفی
   - **آی‌پی مجازی:** مثلاً `10.144.144.1`
   - **پروتکل:** `dual` (ترکیب TCP و UDP)
   - **آدرس پیر (Peer):** خالی بگذارید.
2. از بخش **Node Config**، «کد دعوت یک‌کلیکه» (`xrmesh://...`) را کپی کنید.

### سرور دوم
1. وارد پنل سرور دوم شوید.
2. در تب **Node Config**، کد دعوت کپی‌شده را در کادر پیست کنید تا تمام اطلاعات شبکه به صورت خودکار پر شود.
3. یک آی‌پی اختصاصی (مثلاً `10.144.144.2`) تنظیم کرده و روی ذخیره کلیک کنید.
4. در کمتر از چند ثانیه، ارتباط برقرار شده و وضعیت سرورها در تب Peers نمایان می‌شود.

## جدول دستورات ترمینال (CLI)

تمامی تونل‌های فورواردینگ (HAProxy، Realm، GOST و iptables) و عملیات همگام‌سازی کلاستر مستقیماً از طریق وب پنل مدیریت می‌شوند. دستورات ترمینال شامل موارد کاربردی زیر است:

| دستور | توضیحات |
| :--- | :--- |
| `xraymesh` | باز کردن منوی تعاملی مدیریت در ترمینال |
| `xraymesh token` | تولید لینک موقت یک‌ساعته برای ورود سریع به داشبورد وب |
| `xraymesh password` | تنظیم یا تغییر رمز عبور ادمین وب پنل |
| `xraymesh port` | تغییر پورت وب پنل (HTTP یا HTTPS) |
| `xraymesh ssl` | تنظیم گواهی رایگان امنیتی SSL/TLS (HTTPS) با دامنه |
| `xraymesh remove-ssl` | بازگرداندن وب پنل به حالت ساده HTTP |
| `xraymesh status` | نمایش خلاصه وضعیت سرویس مش، وب پنل و مشخصات نود |
| `xraymesh peers` | نمایش نودهای متصل و تاخیر پینگ لحظه‌ای (EasyTier CLI) |
| `xraymesh routes` | مشاهده جدول مسیریابی هسته شبکه مش |
| `xraymesh logs` | مشاهده لاگ‌های زنده دیمن شبکه مش |
| `xraymesh self-test` | اجرای تست‌های تشخیصی سلامت سرویس‌ها و اتصالات |
| `xraymesh start` | راه‌اندازی یا اعمال تنظیمات نود و استارت تمام سرویس‌ها |
| `xraymesh restart` | ریستارت کلیه سرویس‌های XRayMesh |
| `xraymesh stop` | متوقف کردن کلیه سرویس‌های XRayMesh |
| `xraymesh update` | بروزرسانی خودکار اسکریپت، وب پنل و هسته EasyTier |
| `xraymesh delete` | حذف کانفیگ نود با حفظ فایل‌های باینری و برنامه |
| `xraymesh uninstall`| حذف کامل اسکریپت، سرویس‌ها و فایل‌های مرتبط از سرور |
| `xraymesh version` | نمایش نسخه فعلی نصب‌شده |
| `xraymesh help` | نمایش راهنمای دستورات خط فرمان |
